An entry for the [Fortune Cookie Wisdom for Developers](https://make.fun/c/u-gentle-koala-60-fortune-cookie-wisdom-for-developers-025ccf44) competition on [make.fun](https://make.fun).

## The fortune

> The bug you cannot reproduce is teaching you patience; the one you can is teaching you humility.

## How it works

`main.ts` writes one original fortune-cookie line for a software developer
(96 characters, within the 120-character limit) to `/output/entry.txt`,
where the judge reads it.

## Run

```sh
node main.ts
```

Requires Node 22 or later. The program writes the entry to `/output/entry.txt`.
